# Profil Danis

Dokumen ini merangkum identitas, skill, pengalaman, project, dan narasi pribadi Danis berdasarkan isi portfolio interaktif ini. Gunakan file ini sebagai bahan utama untuk bio portfolio, LinkedIn, proposal freelance, pitch deck, atau halaman About.

## Ringkasan Singkat

Danis adalah developer dari Badung, Bali, Indonesia, dengan fokus utama pada web development dan software systems. Perjalanan coding dimulai sejak kelas 6 SD, lalu berkembang menjadi eksplorasi yang lebih luas di web engineering, AI, cybersecurity, IoT, embedded systems, aplikasi, game, dan project berbasis kebutuhan nyata.

Selama masa SMK, pengalaman tersebut menjadi lebih serius melalui lomba, project client, website perusahaan, sistem akademik, dashboard operasional, dan eksperimen pribadi. Portfolio ini membingkai perjalanan Danis dalam tiga fase besar: The Origin, The Competitor, dan Real World Impact.
